# SpendSense

SpendSense is a personal finance web app I built using Python! I wanted to create something that makes it easier to understand spending habits and make smarter financial decisions. The app uses AI and data analysis to organize transactions, track subscriptions, spot unusual spending, and predict future expenses.

## Features

- Automatically categorizes transactions
- Tracks recurring subscriptions and payments
- Detects unusual spending patterns
- Predicts upcoming expenses
- Interactive dashboard with spending charts and insights

## How to Run

1. Click **Code → Download ZIP** and unzip the folder.
2. Make sure Python 3 is installed.
3. Open Terminal in the project folder and run:

```bash
pip install -r requirements.txt
python -m uvicorn app:app --reload
```

4. Open `http://localhost:8000` in your browser.
